HashSet

is a robust, generic hash set implemented as a thin wrapper around a Map.

Design Philosophy

The HashSet module provides a first-class set abstraction:

  1. Inspection: contains?, length, and empty?.
  2. Mutation: insert!, remove!, and clear! for in-place modifications.
  3. Algebraic: union, intersection, difference, and symmetric-difference for set logic.
