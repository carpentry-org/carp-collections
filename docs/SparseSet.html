SparseSet

is a high-performance collection that maps integer IDs to values. It provides $O(1)$ lookup, insertion, and deletion while maintaining contiguous storage for cache-friendly iteration.

Architecture

  1. Sparse Array: Indexed by the ID. Stores the index into the dense array.
  2. Dense Array: Stores the original IDs contiguously.
  3. Data Array: Stores the values contiguously, matching the order of the dense array.
  4. Count: Tracks the number of active elements.

Performance

Insertion, deletion, and lookup are all $O(1)$. Clear is $O(1)$ (does not drop elements).
