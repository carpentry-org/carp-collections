Stack

is a robust, generic stack data structure implemented as a wrapper around an Array.

Design Philosophy

The Stack module follows a systems-oriented design:

  1. Inspection/Query: Operations like peek and find return Maybe types to handle empty or missing states gracefully.
  2. Mutation with Invariants: Primitives like dup! and swap! enforce stack invariants (e.g. minimum depth) and will call panic! on violation.
  3. Fast Path: unsafe- variants are provided for performance-critical code where the caller guarantees invariants are met.

Safety

The returned pointer may become invalid after any mutation that reallocates the underlying array (e.g. push!, push-all!, extend!, dup!, over!, tuck!).
