carp-collections

Ten container types for Carp, in one package.

Load the whole suite, or any single module on its own:

(load "git@github.com:carpentry-org/carp-collections@master")
; or, for just one:
(load "git@github.com:carpentry-org/carp-collections@master" "deque.carp")

Sequences

  • Deque — double-ended queue over a growable ring buffer, amortized O(1) at both ends
  • RingBuf — fixed-capacity circular buffer
  • Stack — LIFO stack over an array

Sets and maps

  • HashSet — set built on Map, with union, intersection and difference
  • BitSet — dynamic bitset over Uint64 words
  • BitFlags — type-safe integer bitmask, plus the bitflags macro
  • SparseSet — integer ids to values, O(1) and contiguous for iteration

Pools and handles

  • Handle — generational handle into a pool
  • StablePool — generational object pool, O(1) alloc and free, handles stay valid
  • Slot — a single StablePool cell

Priority

  • PriorityQueue — binary-heap priority queue
