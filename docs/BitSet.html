BitSet

is a dynamic growable bitset backed by an array of Uint64 words. It provides extremely compact storage for bit flags and fast set operations.

add!

defn

(Fn [(Ref BitSet a), Int] ()) 

                        (add! bs id)

sets the bit at the specified index to 1. $O(1)$ amortized.

clear!

defn

(Fn [(Ref BitSet a)] ()) 

                        (clear! bs)

resets all bits to 0. $O(n)$ complexity.

contains?

defn

(Fn [(Ref BitSet a), Int] Bool) 

                        (contains? bs id)

checks if the bit at the specified index is set to 1. $O(1)$ complexity.

copy

defn

(Fn [(Ref BitSet a)] BitSet) 

                        (copy bs)

returns a deep copy of the BitSet.

count

defn

(Fn [(Ref BitSet a)] Int) 

                        (count bs)

returns the number of set bits (population count). $O(n)$ complexity.

delete

instantiate

(Fn [BitSet] ())

deletes a BitSet. Should usually not be called manually.

difference!

defn

(Fn [(Ref BitSet a), (Ref BitSet b)] ()) 

                        (difference! bs other)

performs an in-place difference (A - B) with another BitSet. $O(n)$ complexity.

empty?

defn

(Fn [(Ref BitSet a)] Bool) 

                        (empty? bs)

checks if the bitset has no bits set. $O(n)$ complexity (early exit).

equals?

defn

(Fn [(Ref BitSet a), (Ref BitSet b)] Bool) 

                        (equals? a b)

checks if two bitsets represent the same set of bits. Handles cases where one bitset has more trailing zero words than the other.

for-each-set

defn

(Fn [(Ref (Fn [(Ref Int a)] () b) c), (Ref BitSet d)] ()) 

                        (for-each-set f bs)

iterates over all indices of set bits in the bitset. Complexity is currently $O(64 * words)$, which may be slow for very sparse sets.
