Handle

is a generational handle used to safely reference data in a pool. It contains a Uint64 index into the storage array and a Uint32 generation counter to detect stale references.

Identity vs Validity

A Handle represents a stable identity. Whether that identity is currently valid (i.e., refers to an alive object) depends on the state of the pool it originated from. This module handles identity and the "null" state.
