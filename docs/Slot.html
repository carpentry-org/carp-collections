Slot

represents a single storage cell in a StablePool. It tracks its current generation and an optional value.

copy

template

(Fn [(Ref (Slot a) b)] (Slot a))

copies a Slot.

data

instantiate

(Fn [(Ref (Slot a) b)] (Ref (Maybe a) b))

gets the data property of a Slot.

delete

template

(Fn [(Slot a)] ())

deletes a Slot. Should usually not be called manually.

gen

instantiate

(Fn [(Ref (Slot a) b)] (Ref Uint32 b))

gets the gen property of a Slot.

init

template

(Fn [Uint32, (Maybe a)] (Slot a))

creates a Slot.

prn

template

(Fn [(Ref (Slot a) b)] String)

converts a Slot to a string.

set-data

template

(Fn [(Slot a), (Maybe a)] (Slot a))

sets the data property of a Slot.

set-data!

template

(Fn [(Ref (Slot a) b), (Maybe a)] ())

sets the data property of a Slot in place.

set-gen

instantiate

(Fn [(Slot a), Uint32] (Slot a))

sets the gen property of a Slot.

set-gen!

instantiate

(Fn [(Ref (Slot a) b), Uint32] ())

sets the gen property of a Slot in place.

str

template

(Fn [(Ref (Slot a) b)] String)

converts a Slot to a string.

update-data

instantiate

(Fn [(Slot a), (Ref (Fn [(Maybe a)] (Maybe a) b) c)] (Slot a))

instantiate

(Fn [(Slot a), (Ref (Fn [Uint32] Uint32 b) c)] (Slot a))

updates the gen property of a (Slot a) using a function f.
