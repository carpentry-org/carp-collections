Deque

is a robust, generic double-ended queue implemented as a dynamic ring buffer.

Design Philosophy

The Deque module follows a systems-oriented design:

  1. Inspection/Query: Operations like peek-front, peek-back, and nth return Maybe types.
  2. Mutation with Invariants: Primitives like push-front! and pop-back! enforce invariants and will call panic! on violation.
  3. Fast Path: unsafe- variants are provided for performance-critical code where the caller guarantees invariants are met.
  4. Reference Semantics: Higher-order APIs (doall, reduce, etc.) pass references to actual elements in storage to avoid unnecessary copies and support mutation (where safe).
  5. Performance: Key operations like rotation are $O(1)$, and retention is $O(n)$.
