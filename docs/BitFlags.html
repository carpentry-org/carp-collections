BitFlags

is a type-safe wrapper for integer bitmasks.

Design Philosophy

The BitFlags module provides a lightweight, zero-overhead abstraction for managing named bitmasks. It follows a tiered design:

  1. Inspection: contains? (all bits present), intersects? (any bit present), subset?, and empty?.
  2. Mutation: set!, unset!, toggle!, and clear! for in-place modifications.
  3. Functional: with, without, union, intersection, and symmetric-difference for creating new flag sets.

The module also provides a bitflags macro for defining sets of constants with auto-incrementing powers of two.
