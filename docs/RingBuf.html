RingBuf

is a generic fixed-capacity circular buffer.

capacity

defn

(Fn [(Ref (RingBuf a) b)] Int) 

                        (capacity rb)

returns the total capacity of the buffer.

clear!

defn

(Fn [(Ref (RingBuf a) b)] ()) 

                        (clear! rb)

removes all elements from the buffer. Note: this does not zero out the underlying data array; owned values will persist until the RingBuf is dropped or overwritten.

new

defn

(Fn [Int, a] (RingBuf a)) 

                        (new capacity default-val)

creates a new RingBuf with a fixed capacity. Requires a default-val to initialize the underlying array; this value is an initialization artifact and is never exposed by the API (all access is bounds-checked against the logical length). Capacity must be greater than 0.

push!

defn

(Fn [(Ref (RingBuf a) b), a] ()) 

                        (push! rb val)

inserts a value into the buffer. If the buffer is full, it overwrites the oldest element and advances the head.
